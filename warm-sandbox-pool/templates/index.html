About This Demo

This demonstrates the Warm Sandbox Pool technique for eliminating initialization delays when using OpenHands agents.

What's Pre-Installed:

  • Ruby 3.x runtime
  • Sinatra gem
  • Quote service API running on port 4567

Try These Commands:

  • "Check if the quote service is running on localhost:4567"
  • "Fetch a random quote from localhost:4567/quote and show it to me"
  • "List all quotes available in the service"
  • "Show me the Ruby version installed in this sandbox"
💡 For Custom Applications: Replace the demo Sinatra service in sandbox_prep/init_ruby_service.sh with your actual application initialization commands.
